SipSync

SipSync is a smart hydration-tracking bottle prototype built through UW Fitness Tech. It uses embedded hardware, C/C++ firmware, sensor integration, Bluetooth Low Energy, real-time LED feedback, and custom PCB design to track sip data and sync hydration behavior with the MyFitnessTech mobile app.

Project Details

Embedded hardware for smart hydration tracking.

SipSync tracks hydration using an HX711 load cell amplifier paired with a 1–5 kg straight-bar load cell. The system measures changes in bottle weight to estimate sip activity and syncs hydration data to the MyFitnessTech mobile app over Bluetooth Low Energy.

I implemented and integrated the main embedded hardware subsystems, including BLE connectivity, NeoPixel LED control, sensor input, and power regulation. The prototype uses a 3.7 V LiPo battery, TP4056 charging module, DC-DC boost converter, MPU-6050 accelerometer, and a 17-LED WS2812B NeoPixel ring for real-time feedback.

I designed the full circuit, hand-soldered a working protoboard, and wrote C/C++ firmware for hydration feedback states such as drinking, not drinking, and empty. I also designed a custom KiCad PCB for a future compact version of the system.

The early prototype was built on a breadboard to test the load cell, HX711 amplifier, accelerometer, NeoPixel ring, and ESP32 microcontroller. This allowed the hardware team to validate sensor behavior, power requirements, and communication between each subsystem before moving toward a more permanent build.

After validating the circuit, I moved the design onto a protoboard and hand-soldered the system to create a more reliable prototype. This step helped reduce loose wiring issues and made the device easier to test as a connected embedded system.
