Ultrasonic Difference-Frequency Generation

This research project studies how two ultrasonic signals can interact in air to create an audible sound at their difference frequency. In simpler terms, we use speakers that play sounds humans normally cannot hear, then measure whether the air itself helps produce a lower-frequency sound that can be detected by a microphone.

Project Details

Automating acoustic experiments for ultrasonic source reproduction.

This project is inspired by research on acoustic source projection using air nonlinearity. The core idea is that if two ultrasonic tones are played together, the nonlinear behavior of air can produce a new sound at the difference between those two frequencies. For example, two ultrasonic signals around 20 kHz and 23 kHz can create a detectable 3 kHz difference-frequency component.

My work focuses on building and improving the experimental setup used to test this effect. I designed a Fusion 360 positioning rig, wired and programmed stepper motor control in PlatformIO using C/C++, and helped create a synchronized data collection pipeline that coordinates motor movement with microphone capture.

The system logs microphone data into a structured table, allowing experiments to be repeated more efficiently and analyzed more consistently. This automation sped up experimental data collection by approximately 400%.

A major challenge in this project was collecting enough data across different speaker and microphone positions. Manual positioning was slow and inconsistent, so I helped design a motorized positioning setup that could move the microphone or test platform more precisely between measurements.

I implemented C/C++ stepper motor control in PlatformIO and helped synchronize the motion system with microphone data capture. This made it possible to run experiments more quickly while keeping the data organized for later analysis.

I also worked on improving detection of the 3 kHz difference-frequency peak by using 3D-printed speaker fixtures and Python-based FFT and spectrogram analysis. These tools helped evaluate whether the expected audible component appeared in the microphone data and improved peak detection by approximately 25%.
